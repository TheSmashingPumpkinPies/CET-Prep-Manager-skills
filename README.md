# CET Prep Manager Skill

一个面向英语四、六级备考的长期管理 Skill。

它让 AI Agent 能够持续记录学习数据、分析能力变化、追踪错误、调整训练计划，并在不同会话甚至不同 Agent 之间延续同一份备考状态。

## Skill 的用途

你可以用它来：

- 记录四级或六级模考、分项练习和真实考试结果；
- 追踪听力、阅读、写作、翻译的长期变化；
- 按 CET 评分档位评估作文和翻译，并保留估分区间与诊断意见；
- 整理反复出现的错误，判断哪些问题正在改善；
- 根据学习目标、可用时间和实际表现制定版本化计划；
- 记录具体训练，探索训练前后的表现变化；
- 生成 Excel 进度报告、图表和 Markdown 周报；
- 让新的 Agent 从已保存的数据和计划继续工作，而不是依赖聊天记忆。

所有学习历史都保存在本地 SQLite 数据库中。Excel 和 Markdown 是可重新生成的报告，
不会取代原始数据。

## 如何使用

安装并启用 Skill 后，直接用自然语言告诉 Agent 你想做什么即可。例如：

```text
我的目标是六级 550 分，考试日期是 12 月 14 日，每天可以学习 45 分钟。
```

```text
记录今天的六级阅读练习：选词填空 7/10，长篇阅读 8/10，仔细阅读 7/10。
```

```text
请按六级标准评估这篇作文，保存评分，并告诉我最优先修改的两个问题。
```

```text
分析我最近六周的听力和阅读变化，数据不足的地方请明确说明。
```

```text
根据最近表现调整下周计划，但不要因为一次失常就彻底改变安排。
```

```text
生成本周学习报告和 Excel 进度表。
```

Agent 会先读取已经保存的学习状态，再调用确定性的命令行工具完成记录、计算或导出。涉及
历史趋势时，它不应凭聊天印象补全不存在的数据。

## 功能特性

### 持续学习档案

- 保存目标考试、目标日期、目标成绩和每日可用学习时间；
- 使用 SQLite 在会话之间持久化记录；
- 支持多个 Agent 从同一状态继续分析和规划。

### 客观题表现追踪

- 保存听力、阅读练习的正确数、总题数和正确率；
- 计算近期值、MA3、MA5、趋势斜率、波动程度和样本充分度；
- 在数据不足时给出明确提示，不虚构进步或退步。

### 写作与翻译评估

- 使用 14、11、8、5、2 五个 CET 参考档位；
- 保存 `1–15` 估分、分数区间、置信度和结构化诊断；
- 区分 AI 估分与官方人工评分；
- 通过区间重叠和样本量谨慎判断长期变化。

### 错误追踪与复盘

- 按模块、错误代码、严重程度和状态保存具体问题；
- 区分新出现、反复出现、正在改善和已经解决的错误；
- 帮助 Agent 优先处理持续性弱点，而不是只看一次总分。

### 动态训练计划

- 根据目标、弱项、时间预算和历史表现生成计划；
- 每次调整都会生成新版本并保留变更理由；
- 支持追踪计划完成情况和训练记录；
- 避免因单次异常表现频繁推翻整体计划。

### 训练效果分析

- 比较一次明确训练前后的可比表现；
- 至少需要训练前后各两个观测值；
- 结果标记为探索性分析，不把相关性描述成确定因果关系。

### 报告与可视化

- 导出包含模块趋势、错误分布和计划历史的 Excel 工作簿；
- 生成听力、阅读、写作和翻译趋势图；
- 生成区分事实、确定性计算和 AI 解读的 Markdown 周报。

## 分数说明

系统严格区分以下数据：

- **真实官方成绩**：仅记录你实际历次 CET 成绩单上的 `0–710` 分；
- **客观题训练指标**：题目正确数、总题数和正确率；
- **写作与翻译估分**：AI 根据公开评分档位给出的 `1–15` 分估计及区间；
- **诊断指标**：用于训练建议的内部能力维度。

CET 官方成绩涉及常模转换，无法根据一套练习题的原始正确率可靠还原。因此，本 Skill
不会把模考或日常训练换算成所谓“官方分数预测”。

## 补充说明

这是一个面向备考过程动态管理的 Skill，本质上不是让你的 Agent 充当一个“英语老师”的
角色。它不会教给你太多所谓的“提分技巧”。以个人备考四六级的经验，打好词汇基础、吃透
真题就足够了。

## 安装

安装 Python 运行时：

```powershell
python -m pip install `
  "git+https://github.com/TheSmashingPumpkinPies/CET-Prep-Manager-skills.git"
```

然后让支持 GitHub Skill 安装器的 Agent 从
[`skill/`](https://github.com/TheSmashingPumpkinPies/CET-Prep-Manager-skills/tree/main/skill)
子目录安装 Skill，并命名为 `cet-prep-manager`。

也可以先克隆仓库，再手动复制。以 Windows 上的 Codex 为例：

```powershell
git clone https://github.com/TheSmashingPumpkinPies/CET-Prep-Manager-skills.git
Set-Location .\CET-Prep-Manager-skills
Copy-Item -Recurse -Force .\skill "$env:USERPROFILE\.codex\skills\cet-prep-manager"
```

安装完成后，可以先让 Agent 执行：

```text
初始化四/六级备考档案，并告诉我接下来需要提供哪些信息。
```
